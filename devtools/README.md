# Partisans devtools

Nothing here ships. `release.sh` leaves the whole folder out.

| Path | What it is |
| --- | --- |
| `harness/pt-lab.js` | The in-game steps behind the acceptance checks in `docs/DESIGN.md`: survey the game, culture-flip a settlement with the probe marker, put a settlement into misery, start a rising through the mod's own pipeline, run the pass, change relations, slot a policy card, watch the settlements and the independents' units, seed the mod's rolls. Driven through `globalThis.__towerPartisans`. |
| `harness/p.sh` | Runs one step in the tower-bench lab game and prints its result: `./p.sh survey`, `./p.sh flip '{"x":63,"y":32,"toPid":0}'`. Refuses to run against a game the lab didn't start. |
| `probe-mod/` | A throwaway data mod for the checks: `BUILDING_PTPROBE_CULT_<LEADER>` hands the settlement holding it to that leader by culture (the transfer Cultural Diffusion's whole-settlement flip produces), and `BUILDING_PTPROBE_UNH` takes 15 Happiness off the settlement holding it. Generated by `gen-probe.mjs`. |
| `probe-short-age/` | A twenty-turn Antiquity, for the age-transition check only. |

## A lab run

```
# from the workspace root
node tools/tower-bench/tower-bench.mjs mods                       # nobody else holds the game; see which copies are live
cp -r tower_mods/partisans/devtools/probe-mod "$MODS/pt-probe"    # $MODS = ~/Library/Application Support/Civilization VII/Mods
node tools/tower-bench/tower-bench.mjs deploy tower_mods/partisans --yes   # the game's copy of the mod
node tools/tower-bench/tower-bench.mjs lab start --seed 4242 --age AGE_ANTIQUITY
tower_mods/partisans/devtools/harness/p.sh survey
...
node tools/tower-bench/tower-bench.mjs lab stop                   # restores saves, options and the registry
rm -r "$MODS/pt-probe"
```

The lab backs up the mod registry before the game starts and puts it back at `lab stop`; the probe mod folder is the
one thing to remove by hand. A probe mod registers itself the first time the game launches with it in `Mods/`, so the
first lab start after copying it in only registers it; the second loads it.

The mod's log lines carry the `[Partisans]` prefix in `Logs/UI.log`. `debug` in the settings slice turns on the
per-plot placement lines.
